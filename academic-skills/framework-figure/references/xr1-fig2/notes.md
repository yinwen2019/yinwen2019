## 科学上下文

- **问题与动机**：VLA 需要把高维感知转换为精细控制，同时吸收不同机器人与人类演示中的互补知识。仅从视觉变化或动作单一模态学习潜变量，难以兼顾通用语义与控制精度。
- **Stage 1**：双分支 VQ-VAE 编码视觉动态与机器人运动，在共享离散码本中量化。视觉分支依据当前/未来帧学习未来帧预测；运动分支依据动作与本体状态学习运动重建。两种量化表示组合为 Unified Vision-Motion Codes（UVMC），并以跨模态对齐约束关联视觉与运动。无动作标注的人类演示仅参与视觉分支目标，不能画成人类视频自带机器人动作标签。
- **Stage 2**：将观测、语言和 learnable tokens 输入 VLM，以第一阶段 UVMC 监督其预测，结合动作损失进行跨机器人预训练。图中绿色跨阶段虚线连接 UVMC 与预训练中的监督目标，MSE 标记强调该对齐关系。
- **Stage 3**：用任务数据和动作目标进行下游微调，保留 VLM 与 Action Head 的主体结构。三个面板是训练阶段，不是推理时必须依次经过的三套网络；也不能把第二阶段专属的 UVMC 监督默认搬到部署阶段。
- **图的范围**：阶段级数据与模块协作、共享表示、预训练到微调的结构复用；精确损失项和全部实现细节由正文补充。

## 视觉分析

- **布局与阅读顺序**：左上竖列展示多源数据；上方宽面板给 Stage 1 及 UVMC 最大面积；下方并排放 Stage 2 与 Stage 3。先读上层表示学习，再读下层预训练与微调，体现阶段依赖和创新重点。
- **模块与连接**：视觉/运动编码器、UVMC、对应解码器横向排列；上下两个模态通过位置与颜色对齐。Stage 2 和 Stage 3 使用近似布局，以数据来源、辅助 token 与监督项的差异体现阶段变化，减少读者重新辨认主体结构的成本。
- **箭头语义**：橙/蓝箭头对应视觉/运动分支；跨面板绿色虚线表达 UVMC 监督迁移；底部动作序列的回弯箭头表达动作头中的处理路径。不同虚线还用于边界和 token 分组，应结合位置与标签理解，不能统一解释为“冻结”或“可选”。
- **配色与图形**：浅蓝大背景承载表示学习，紫色 UVMC 面板强调核心创新；视觉模块浅桃色、运动/动作模块浅蓝色；小色块区分输入、可学习 token 与动作。数据照片、码本格子、轨迹与网络图标把抽象模块具体化。
- **字体与层级**：阶段标题大、模块标签次之、token 与时间索引最小；主标签以无衬线为主，数学时间/动作标记使用数学字形。深色轮廓和较粗箭头强化模块边界，但图的密度较高。
- **可迁移**：适合“表示预训练 → 通用策略学习 → 下游适配”的三阶段方法；可借鉴上大下双栏、创新模块居中突出、后两阶段复用视觉骨架，以及监督关系跨面板显式连接。
- **可改进处**：原图中 Action Sequence 被生硬换行，部分竖排文字与底部小标签缩小时难读；新图应改善断行与字号。图标、阴影、码本内部曲线与粗描边不应全盘变成默认偏好。
