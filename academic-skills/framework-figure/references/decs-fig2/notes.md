## 科学上下文

- **问题与动机**：推理模型会在已得到正确答案后继续冗长思考。整条序列的长度奖励与 token 级优化不完全一致，可能压制必要探索，同时仍奖励部分冗余内容。
- **必要推理前缀**：NRP 表示首次足以得到正确答案的最短前缀；实现中用轻量生成式判断器，依据题目和标准答案检查推理片段，定位首次包含正确答案的片段边界。
- **解耦奖励**：区分必要前缀、冗余思考和最终答案；对正确回答的必要部分与答案保持高奖励，对冗余部分使用随长度降低的奖励，再计算 token 级组相对优势并更新策略。奖励数值和优势正负不是同一概念，图中首个冗余 token 的负优势是关键，不能把所有红色内容都简单解释为负奖励。
- **课程调度**：以批次中正确回答的 NRP 占比变化调整易题比例，让冗余压缩随训练进展推进，避免过早抑制探索。奖励/优势同时反馈给策略更新，NRP 占比反馈给下一步数据组成。
- **图的范围**：以一个简单算术题及多条回答演示检测、奖励和数据调度的训练闭环；不是部署时串联调用策略、判断器及课程调度器的推理系统。

## 视觉分析

- **布局与阅读顺序**：上方从左到右依次为题目、策略、生成回答、NRP 检测与切分后的回答；右下大面板展开奖励分配。随后沿底部两条回路返回策略与数据采样，阅读路径体现训练反馈。
- **样例与对齐**：同一组回答在生成、切分和奖励面板中保持行对应；色块长度与文字片段共同表达必要内容和重复思考。省略号压缩组内样例数量，答案块在各面板保留稳定位置。
- **箭头语义**：上方较粗三角箭头表示处理顺序；下方两条独立直角返回线分别表达 PPO 策略更新和课程比例更新，不能合并成同一种数据流。旋转图标辅助表达反复训练。
- **配色与纹理**：奖励面板用蓝色表示 NRP、绿色表示答案、红色表示冗余，额外用横纹/网格区别首个与末尾冗余 token。右侧图例解释类别和优势含义，前后面板的淡色背景区分操作区域。
- **字体与层级**：手写风标签与黑色图标较醒目，公式使用数学字形；主操作标题较大，样例文字次之，图例最小。圆角边框与阴影帮助分组，但手写字形和阴影并非方法必需。
- **可迁移**：适合奖励塑形、样本重加权、动态采样等训练方法；可借鉴“同一具体样例逐步变换 + 局部规则展开 + 两种反馈分开标注”。
- **可改进处**：公式、长图例和四行重复样例占较多面积；新图可按贡献保留必要行数，明确区分 reward 与 advantage，并检查小字号和公式的印刷可读性。
