# Intro Figure

把论文引言的核心论点转成读者能顺着图读懂的视觉叙事。优先呈现问题、局限与关键思想之间的联系。在需要展示任务或能力时，使用当前论文支持的例子或结果。

## 使用参考库

- 默认读取同目录的 [preferences.md](preferences.md) 和 [references/](references/)。用户指定 `library_root` 时，使用该目录的偏好与参考记录。
- 每次设计重新读取最新的偏好与全部 `references/*/notes.md`。参考图平铺保存，按表达需要在全库查找。Conceptual 与 teaser 是可组合的表达方式。
- 当前论文、用户描述和澄清提供科学事实。视觉选择依次采用本次明确要求、适用的已确认偏好、单条参考的已确认反馈及临时设计判断。借用他人的库时保留其偏好归属。

## 1. 先确定引言叙事

阅读题目、摘要和引言。必要时查看与核心思想相关的方法段落、例子或实验。用一句话概括读者看完图后应该理解的观点，再提取背景任务、可具体示例化的现有局限、本文洞察，以及有依据的能力或效果。区分论文中报告的结果、解释机制的示意和拟议效果。

当局限是抽象机制时，可用 conceptual 示意把它变成可观察的现象，再连接到对应的设计思想。当任务、输入输出或能力更易用例子理解时，可用 teaser 组织同一任务的例子、简短对照与本文结果。两种方式可组合，围绕同一句主张。若缺失事实会改变局限与回应的对应关系，先澄清该点。其他版式细节可按论文栏宽和内容临时选择。

## 2. 全库选图并归纳表达

先比叙事结构与表达目标，再考虑论文主题和视觉相似度。例如，两个独立局限各有对应回应时，优先找一一对应的例图。需要展示一个具体失败案例时，优先找任务与结果能用同一输入对照的例图。

打开候选图片核对笔记，按需回看图注或引言。为每张入选图写清借鉴的部分及其适用条件。结合所选图片归纳本次可用的布局、元素、配色和视觉层级，再据当前论文重新组织。单张合适参考即可使用。库为空、图片未核验或没有合适图时，可用当前论文完成方案，并说明可用的参考依据。

## 3. 设计图面

- 以读者需要理解的顺序分区，明确哪些元素展示问题、哪些元素展示回应。用对照、局部放大、空间分组或连线建立对应。箭头含义由论文关系决定。
- 每个主要局限尽量落到具体案例、现象或概念示意。保留解释核心思想所需的方法细节。完整训练和推理流程交给主框架图。
- 用颜色、形状和字体层级突出关键差异。面板数量、画布比例和密度由叙事与版面决定。最终按目标栏宽检查标签、间距与阅读顺序。
- 图示用语与原稿一致。用明确标注区分定性示例、概念示意与有数值依据的结果。有歧义的箭头、比较条件和量化标注需要核对。

## 4. 交付与反馈

1. **中文设计说明**。给出图的主张、分区与阅读顺序、局限如何对应回应、图中重点及参考图的借鉴范围。
2. **参考图列表**。将实际看过并能交付为附件的图按 `Reference 1` 等编号，写明文件路径、论文出处与借鉴内容。只有笔记时标明文字依据。
3. **完整英文提示词**。包含当前论文的科学主张、可用的示例或对照、分区、英文短标签、连线语义、布局和参考图使用范围。提示词中的附件编号与实际图像一致，使用时把对应图片和文字一起交给生图工具。

用户可在同一对话继续提供论文、替换图或视觉反馈。收到明确的入库或长期偏好更新要求时，按 [figure-library](../figure-library/SKILL.md) 更新指定库中的图片、上下文与偏好记录。后续设计从更新后的文件读取。当次方案反馈先用于当次设计。
